## Trabajo práctico INTEGRADOR de la asignatura DCI

Este repositorio contiene el trabajo práctico final para la asignatura de Diseño de Circuitos Impresos de la carrera de posgrado de FIUBA.

- Autor: Guido Potente
- Título corto del trabajo: Sensado de calidad de aire/ambiente (IEQ).
- Descripción: El objetivo es crear un pequeño PCB que pueda conectarse unicamente con 4 pines para I2C (GND, 3V3, SDA y SCL) que tenga los sensores necesarios para medir un conjunto de variables imporantes para el ambiente dentro de una habitacion.
- Cursada: OCT-NOV-DIC 2026
